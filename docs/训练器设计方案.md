# MCI 分类训练器设计方案（Trainer Design）

> 依据论文《An Integrated Learning Framework for White Matter Connectivity-Based Cognitive Impairment Staging》及补充材料 S1–S7 设计。
> 运行形态：无图形界面，VSCode launch.json 调试 + CLI 脚本驱动。

---

## 1. 设计目标

搭建一个覆盖论文全流程的实验训练器，支持：

1. **8 个模型变体**训练：4 骨干（Transformer / ResNet / FCN / LSTM）× {Baseline, Enhanced}（+CBAM / +ASPP / +SE / +SGE）。
2. **论文指标**：OvR 口径的 ACC、AUC、SEN、SPE（S20–S22），100 次重复留出实验的 mean ± std（S23）。
3. **论文调参流程**：Optuna 两阶段贝叶斯优化（20 + 10 trials，10 折 CV 目标函数）。
4. **论文验证方法**：100 次重复随机留出（80:20），baseline 与 enhanced 共享同一划分做配对比较。
5. **分析管线**：top-20 关键连接与选择频率、Mantel 检验（1000 置换 + FDR）、Pearson 相关、Lasso + SHAP（top-12 相对贡献）。
6. **数据收集与展示**：每 run 落盘 JSON/CSV，自动汇总成 Table 2 式表格、Fig 5/6/7/8/9/10 对应数据。

## 3. 运行环境（严格按论文 §2.6）

### 3.1 正式实验环境（目标机器）

| 项目 | 规格 |
| --- | --- |
| GPU | 2 × NVIDIA GeForce RTX 4090（24 GB each） |
| OS | Ubuntu 22.04 LTS |
| CUDA | 12.1 |
| Python | 3.10.12 |
| PyTorch | 2.3.1+cu121 |
| torchvision | 0.18.1+cu121 |

其余依赖（版本锁定于 `requirements.txt` / `environment.yml`）：optuna、scikit-learn、shap、numpy、pandas、scipy、matplotlib、pyyaml、tqdm。

### 3.2 双 4090 使用策略

本任务数据量小（150 被试，batch ≤ 64，模型均为轻量结构），单模型双卡 DDP 无收益，因此**采用作业级并行**（这也是论文表述"using two RTX 4090"最自然的用法）：

- 训练进程本身**单进程单卡**，通过 `--device-id` 或 `CUDA_VISIBLE_DEVICES` 绑定 GPU。
- 实验矩阵（8 变体 × {调参, 100 次留出}）构成作业队列，由 `scripts/schedule_all.py` 按空闲 GPU 分派：
  - 典型分法：GPU0 跑 Transformer/FCN 系，GPU1 跑 ResNet/LSTM 系；或 GPU0 跑 4 个 baseline、GPU1 跑 4 个 enhanced（天然配对同步）。
- 同一变体的 100 runs 支持 `--shard i/n` 分片，两个进程各跑 50 个 seed。
- 期望耗时量级：800 次完整训练（8 变体 × 100）+ 调参 30 trials × 10 折 × 8 变体 ≈ 3200 次短训练，双卡分摊；断点续跑保证中断不重算。

### 3.3 开发调试环境（本机，非正式实验）

Windows + 单卡 RTX 3090，仅用于 VSCode 开发、断点调试与冒烟测试。代码跨平台：`pathlib` 路径、`num_workers=0` 可配、GPU 数量自动检测；依赖同一份 `requirements.txt`（Windows 下装 cu121 wheel 即可）。

## 5. 数据层

### 5.1 数据规范（真实数据按此提供）

- `subjects.csv`：`subject_id, group(NC/EMCI/LMCI), mmse, faq, gds`（可选 `age, sex, education` 用于复现 Table 1）。
- `connectivity/{subject_id}.npy`：90×90 float，白质结构连接强度（AAL 90 区）。
- `md/{subject_id}.npy`：90×90 float，对应连接的平均扩散率（MD）——临床关联分析（§2.5）必需。
- 也支持堆叠格式 `connectivity.npy (N×90×90)` + `md.npy`。
- `validate_data.py` 检查：形状、对称性、NaN/Inf、标签分布、临床分数缺失，输出 Table 1 式人口学统计。

### 5.2 预处理（config 可调，默认与论文一致）

对称化 `(A+Aᵀ)/2` → 对角线置 0 → 逐被试归一化（max-scaling，可选 z-score）。论文"consistent scaling and normalization"未给细节，作为 config 项留出，保证 base/enh 与所有变体用同一套预处理。

### 5.3 Mock 数据

`make_mock_data.py` 按 NC=54 / EMCI=42 / LMCI=54 生成带类别相关边缘信号的模拟矩阵 + 模拟临床分数，使全管线（训练→调参→100 runs→分析）在真实数据到位前即可端到端验证。

## 6. 模型层（按补充材料公式实现）

| 变体 | 输入表示 | 骨干 | 增强模块（插入位置） |
| --- | --- | --- | --- |
| Transformer / +CBAM | 90 个 ROI 行向量作为 token（90×90）→ 线性投影 d_model + 位置编码（S2） | L 层 encoder：MHA(H heads) + FFN + LayerNorm（S3） | CBAM：通道注意(avg+max→共享MLP→sigmoid) 串联位置注意(avg+max→Conv1D→sigmoid)，作用于 encoder 输出表征（S4–S5） |
| ResNet / +ASPP | 90×90 单通道图 | 残差块堆叠（3×3 conv+BN+act；维度不等时 1×1 projection shortcut）→ GAP → FC（S6–S7） | ASPP：1×1 conv ∥ 3×3 空洞卷积{r=6,12,18,24} ∥ global 分支 → concat → 1×1 conv+BN+act（S8–S9），插入残差阶段之后 |
| FCN / +SE | 90×90 单通道图 | 堆叠 3×3 conv+BN+ReLU → GAP → FC（S10–S11） | SE：GAP→FC 降维→ReLU→FC 升维→sigmoid→逐通道加权（S12–S13），作用于最终特征图 |
| LSTM / +SGE | 90 步序列，每步为该 ROI 的 90 维连接向量（S14） | LSTM（i/f/o 门 + 细胞态）→ 末步隐状态 → FC（S15） | SGE：通道分 G 组→组内位置与全局描述子点积→跨位置标准化→γ,β 仿射→拼接（S16–S17），作用于 LSTM 输出序列 |

- 结构超参（d_model、heads、层数、通道数、G、dilation rates）全部进 config，默认值合理即开即用。
- `registry.py` 注册 8 个变体名，CLI `--variants transformer_cbam` 直接引用。
- 每个模型输出 `logits(3)` 与 `softmax 概率`（供 OvR AUC）。

## 7. Trainer（单次训练）

按 §2.4 逐条实现：

- **损失**：多类交叉熵（S18）。
- **优化器**：`torch.optim.AdamW`（S19），`lr` / `weight_decay` / `batch_size` 来自 config 或调参结果。
- **学习率调度**：5 epoch 线性 warmup → cosine annealing 至 `min_lr=1e-6`（`scheduler.py` 自定义）。
- **轮数**：max 100 epochs；**early stopping**：val loss 连续 15 epoch 无改善即停；**checkpoint**：保留 val loss 最低的权重用于测试评估。
- **AMP**：`torch.cuda.amp.autocast` + `GradScaler`（论文明确开启）。
- **验证集来源**：
  - 留出实验：80% 训练内部再分层切 10% 作 val（early stop / ckpt 依据），20% 作 test；
  - 调参：10 折 CV 的验证折作 val。
- **记录**：每 epoch 的 train/val loss、acc、lr 存入 `history`；全局 seed（torch/numpy/random）可复现。
- **设备**：`--device-id` 绑定单卡；无 CUDA 自动回退 CPU（冒烟测试用）。

## 8. Tuner（Optuna 两阶段贝叶斯，§2.4）

- **搜索空间**：`lr` log-uniform[1e-5, 1e-3]；`weight_decay` log-uniform[1e-6, 1e-3]；`batch_size` ∈ {16, 32, 64}。
- **目标函数**：10 折分层 CV 的 mean val ACC（config 可切 val loss）；每折训练沿用 Trainer 全部规则（early stop、AMP 等一致，epoch 上限可配短版以控制调参耗时）。
- **两阶段**：
  - 阶段一：TPE 采样 20 trials，全域搜索；
  - 阶段二：以阶段一 top-3 试验为中心收缩连续参数范围（log 空间 ±0.5 个数量级内、不越原始边界；batch 保留 top-3 出现过的取值），再 10 trials；
  - 合并 30 trials 取最优。
- **输出**：每变体 `tuning/best_params.json` + `trials.csv`（全部试验记录）。baseline 与 enhanced 走完全一致的调参流程（论文要求 consistent procedures）。

---

## 9. HoldoutRunner（100 次重复随机留出）

- 外层循环 seed = 0…99：分层 80:20 划分（每类按比例）。
- **配对比较**：同一 seed 下 baseline 与 enhanced 使用完全相同的划分与预处理（Table 2 的 Base vs Enh 可配对）。
- 每 run 落盘 `runs/run_{seed:03d}.json`：划分索引、超参、epoch history、test OvR 指标、softmax 概率、（可选）特征重要性。
- **断点续跑**：已存在且完整的 run 自动跳过；**分片** `--shard i/n` 支持双卡两进程分摊 100 runs；`--variants` 指定子集。
- 双卡调度由 `schedule_all.py` 统一分派（§3.2）。

---

## 10. 指标（eval/metrics.py）

- **OvR 口径**（S20–S22）：对每个类 c（NC/EMCI/LMCI）以 c 为正类、其余两类为负类：
  - `ACC_c = (TP+TN)/(TP+TN+FP+FN)`，`SEN_c = TP/(TP+FN)`，`SPE_c = TN/(TN+FP)`；
  - `AUC_c` = softmax 概率 p_c 对二值标签的 `roc_auc_score`。
  - 另报整体 3 类 accuracy 供参考。
- **汇总**（S23）：100 runs 的 mean ± std；`summarize` 自动生成：
  - `table2.csv` / `table2.md`：Stage × Backbone × {Base, Enh} × {ACC, AUC, SEN, SPE}，与论文 Table 2 同构；
  - `metrics_distribution.csv`：每 run 指标明细（Fig 5 箱线图数据）；
  - `roc_data.npz`：池化概率与标签（Fig 6 ROC 曲线数据）。

## 11. 特征重要性（§3.5，Fig 7/8）

论文未指明重要性算法，训练器默认**边级排列重要性**（模型无关、8 变体可比）：test 集上逐一 shuffle 某条边（上三角 4005 条）取值，记录 OvR-ACC（或整体 ACC）下降量。备选 `gradient×input`，config 切换。

- 每 run 计算并落盘 → 100 runs 聚合：
  - 平均重要性排名 → EMCI / LMCI 各自 **top-20** 连接（带 AAL 解剖标签，含 Table S1 缩写映射）；
  - **选择频率**：每条连接进入 top-20 的 run 占比（重要性稳定性分布）；
  - **共有 vs 特有**：两 stage top-20 集合的交集/差集（§3.5 的 5 条共有连接类分析）。

> 性能注记：4005 边 × 30 test 样本的 shuffle 评估很快（纯前向），如需加速可配置仅对每 run top-K 边精算。

## 12. 临床关联分析（analysis/）

输入：top-20 连接（来自 §11）的 **MD 特征** + 临床分数（EMCI / LMCI 内各自进行）。

1. **Mantel 检验**（S24–S26）：连接 MD 欧氏距离矩阵 vs 各临床分数绝对差距离矩阵；统计量 = 两矩阵上三角元素 Pearson r；**1000 次置换**得 p 值；stage 内对 MMSE/FAQ/GDS 三个 p 做 **BH-FDR 校正**，q<0.05 显著。输出 `mantel_results.csv`（r、原始 p、q、显著性）。
2. **Pearson 相关矩阵**（S27）：20 条连接 MD 值两两相关（Fig 4 下三角热图数据）。
3. **Lasso**（S28）：stage × score 共 6 个模型；特征标准化；`LassoCV`(10 折) 自动选 α（论文未指定 α 选择方式，采用 CV 选择并记录）。
4. **SHAP**（S29–S32）：对 Lasso 用 `shap.LinearExplainer`：
   - `mean|SHAP|` 排序 → 特征重要性；
   - 每样本 SHAP 值矩阵落盘（beeswarm 数据，Fig 9/10 上板）；
   - **top-12 相对贡献 %** = 各连接 mean|SHAP| / 全特征总和，余项合并为 C_others（S32，Fig 9/10 下板数据）。
5. 输出跨 stage、跨表型的共有/特有预测特征对照表。
